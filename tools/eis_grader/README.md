# EIS 電池優劣判定工具

給一顆電池的 EIS（電化學阻抗頻譜）數據，自動判定電池等級（A/B/C/D），並用**蒙地卡羅**估計判定的可信度。

## 使用方式

```bash
pip install -r requirements.txt

# 1) 有一顆全新（基準）電池的 EIS
python -m eis_grader 待測電池.csv --ref 全新電池.csv

# 2) 已知全新電池的內阻（Ω），例如規格書或出廠數據
python -m eis_grader 待測電池.csv --r0-new 0.020 --rp-new 0.018

# 3) 一批電池（≥3 顆）互相比較、挑出異常者（以批次中位數為基準，屬相對排序）
python -m eis_grader cells/*.csv
```

輸出在 `eis_report/`：每顆電池一張圖（Nyquist 擬合 + 蒙地卡羅分佈）與 `report.json`。
範例資料在 `examples/`：`python -m eis_grader examples/cell_*.csv --ref examples/fresh_ref.csv`

## 輸入格式

CSV / TXT，欄位為頻率、Z'、Z''。會自動辨識：

- 分隔符號：逗號、Tab、分號、空白
- 表頭名稱：BioLogic（`freq/Hz`、`Re(Z)/Ohm`、`-Im(Z)/Ohm`）、Gamry（`Freq`、`Zreal`、`Zimag`）等；沒有表頭時，依序當作 頻率、Z'、Z''
- Z'' 的正負號（存 Z'' 或 −Z'' 都可以）
- 單位 Ω 或 mΩ（表頭含 `mOhm` 時）

## 判定流程

1. **數據品質**：用 Lin-KK（Kramers-Kronig）檢查量測是否穩定、線性；殘差 > 2% 會加上警告。
2. **等效電路擬合**：`L – R0 – (R1‖CPE1) – (R2‖CPE2) – W`
   - R0：歐姆內阻（電解液、接點、集流體）
   - R1：SEI／表面膜
   - R2：電荷轉移
   - Rp = R1 + R2：極化電阻
3. **蒙地卡羅**：以擬合殘差估算雜訊大小，產生 N 組（預設 200 組）模擬頻譜並逐一重新擬合，得到 R0、Rp 的 95% 區間，以及每個等級的機率。
4. **分級**：以內阻成長倍率（相對基準）判定，R0 與 Rp 取較差者：

   | 等級 | 成長倍率 | 意義 |
   |---|---|---|
   | A | ≤ 1.25× | 良好 |
   | B | ≤ 1.5× | 尚可 |
   | C | ≤ 2.0× | 老化 |
   | D | > 2.0× | 劣化，建議汰換（內阻加倍是業界常用的壽命終點） |

   SOH_R = 以總內阻計算，全新時為 100%，內阻加倍時為 0%。

## 隨機森林（有已標記數據時）

有已知 SOH 或好壞的電池（建議 ≥ 30 顆）時，可以訓練隨機森林，讓門檻從你自己的數據學出來。

**1. 準備標籤檔** `labels.csv`，和 EIS 檔放在同一個資料夾：

```csv
file,soh
cell01.csv,96.2
cell02.csv,81.5
```

只有好／壞分類時，把 `soh` 欄位換成 `label`（例如 `good` / `bad`）。

**2. 訓練**

```bash
python -m eis_grader.train labels.csv --out model.joblib
```

會用 5-fold × 10 次重複交叉驗證評估，並跟「只用總內阻」的簡單模型比較。**隨機森林沒有比較好時，會直接告訴你**；數據少時這種情況很常見。

**3. 預測新電池**

```bash
python -m eis_grader 新電池.csv --model model.joblib
```

特徵來自等效電路擬合，共 20 個：R0、R1、R2、CPE 指數、時間常數、Warburg，以及 1 kHz 到 0.1 Hz 的 |Z| 與相位。預測時，每一組蒙地卡羅重新擬合的參數都會送進模型，所以輸出有兩種誤差：

- **量測雜訊區間**：來自蒙地卡羅
- **模型誤差**：來自交叉驗證的 MAE，通常比較大

判斷一顆電池時，兩者都要看。

## 注意事項

- EIS 受**溫度與 SOC** 影響很大，待測電池與基準電池必須在相同條件下量測（例如 25 °C、50% SOC、靜置後）。
- 分級門檻（`eis_grader/grade.py` 的 `DEFAULT_GRADES`）是通用預設值。如果你有同型號電池的實際容量衰退數據，應該用它來校正門檻。
- 蒙地卡羅的可信度只反映**量測雜訊與擬合不確定性**，不包含模型本身的誤差，也不包含溫度與 SOC 差異造成的偏差。
